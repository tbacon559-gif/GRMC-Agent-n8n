# Deployment Guide

The current deployment process (Vercel + Neon) is documented in the
README's "Deploying" section — see `/README.md#deploying-vercel--neon`.
This file will absorb and expand that content once deployment grows
beyond a single Next.js app on Vercel (e.g. if an OS is ever split out
as its own service, per `docs/architecture/01-system-architecture.md`'s
note on the module-manifest boundary being the future extraction seam).
